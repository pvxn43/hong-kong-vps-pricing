## 便宜机的三个真实限制

**硬盘 10G，装完 Docker 就紧。** 镜像、日志、数据库各占一块，10G 很快见底，先升配置比事后迁移省事。要装面板、跑数据库、留几天日志，20G 起步。

**1G 内存跑 WordPress 能起来，但撑不住。** WordPress 加 MySQL 再加 Nginx，1G 内存能启动服务，插件一多或者来一波流量就容易 OOM。建站按 2G 起步算，1G 留给探针、跳板、轻量 API 这类用途。

**国际线的晚高峰，取决于你本地运营商。** 这类机器从国内访问，延迟靠的是香港离得近；晚高峰会不会绕路、丢包多不多，买之前没人能保证。同一台机器，白天和晚上八点可能是两种体验。国内访客为主、又要求晚高峰稳定，这类机器不合适。

## 线路要对上你家的宽带

- 电信：优先 CN2 GIA，其次三网直连（去程走 CN2 的那种）
- 联通：9929（CUII）或 CMI
- 移动：CMI、CMIN2

几个术语对应一下。CN2 GIA 是电信双向精品网，电信用户体验最好，联通移动走这条线一般；CMI 是移动国际精品，移动联通都不错，电信稍弱；9929 也叫 CUII，是联通精品网；AS10099 是联通国际（CUG），成本比 CN2 GIA 低一档，属于够用不贵的优化；普通 BGP 走公网自动选路，延迟均衡，峰值不如专线稳。

Akile HKPlus 记录里那个组合（电信联通 CUG、移动 CMI）就落在中间层：比纯国际线稳，比 CN2 GIA 便宜。这也是大多数预算敏感的人实际该看的一档。

## IP 属性决定这台机器能干什么

香港机的 IP 大致分三档：原生 IP、住宅/双 ISP IP、机房 IP。

港区 Netflix、Disney+ 这类流媒体，原生 IP 基本直接能开。TVB 直播、Cityline 购票、香港本地社媒运营，要的是住宅 IP，也就是来自 HGC、iCable 这类香港本地宽带运营商的地址，在平台眼里等同于普通香港家庭用户。只要一个香港出口、不涉及本地服务，机房 IP 最便宜，也够用。

便宜机绝大多数是机房 IP，被流媒体平台识别、拒绝的概率高。买之前先想清楚你要的是“一个香港 IP”还是“一个香港本地居民身份”，这两件事对应的套餐完全不是一回事。另外，住宅 IP 也不是永久解锁，平台风控一更新就可能失效，这是行业共性。
